## 1. 访问与登录

1. 浏览器打开系统地址（Docker 部署默认 `http://localhost:8081`，本地开发 `http://localhost:5173`）；
2. 输入账号与密码，点击【登 录】；未注册用户点击【注册一个】选择角色后注册；
3. 登录成功后进入就业数据看板；顶栏右侧显示当前用户与角色，并显示 AI 状态标签
   （"AI：deepseek"表示已接入大模型，"AI：本地规则模式"表示降级运行）；
4. 点击右上角用户区可【个人档案】或【退出登录】。

演示账号（密码均为 `123456`）：`student01`（学生）、`counselor01`（辅导员）、`hr01`（企业HR）、`admin01`（院系管理员）。

## 2. 学生操作指南

### 2.1 完善个人档案（建议第一步）

1. 左侧菜单进入【个人档案】；
2. 填写姓名、手机号、邮箱、学院、专业、年级、学历，重点填写：
   - **技能标签**：用逗号分隔，如 `Java,Spring Boot,MySQL,Redis`；
   - **求职意向**：城市 + 方向，如 `成都 Java后端开发`；
3. 点击【保存档案】。

> 档案完整度直接影响岗位匹配得分（技能 40 分、学历 15 分、专业 15 分、意向 15 分、完整度 15 分）。

### 2.2 简历登记与 AI 诊断

1. 进入【智能简历】→ 点击【新增简历】；
2. 填写简历标题、目标岗位，并把简历正文粘贴到"简历正文"框（后续版本支持 PDF/Word 自动解析）；
3. 点击【保存】，列表中点击【AI 诊断】；
4. 右侧抽屉展示诊断报告：**总分、等级、优势、不足、修改建议、缺失关键词**；
5. 按建议修改后重新诊断，可对比分数变化（点击【查看报告】查看最近一次结果）。

### 2.3 岗位匹配与投递

1. 进入【岗位匹配】，可按关键词、城市筛选；
2. 点击【智能匹配】查看匹配结果：匹配分数（仪表盘）、匹配等级、命中技能、缺失技能、打分依据与智能体解读；
3. 点击【一键投递】完成投递（系统会拦截重复投递）；
4. 投递记录可通过接口 `/api/jobs/my/applications` 查询，状态含义：
   `SUBMITTED` 已投递 → `VIEWED` 已查看 → `INTERVIEW` 面试中 → `OFFER` 已录用 / `REJECTED` 未通过。

### 2.4 实习申请与日志

1. 进入【实习管理】→【提交实习申请】，填写实习单位、岗位、起止日期与备注；
2. 提交后流程进入"企业导师审批"，可在列表查看当前节点与状态；
3. 点击【流程轨迹】查看每次审批的操作人、节点、意见与时间；
4. 实习期间点击【提交日志】，按"本周任务 / 完成情况 / 问题与解决 / 下周计划"结构填写，提交后由辅导员批阅；
5. 实习结束由学生自评、企业导师评价、校方评定三方打分，系统按 20% / 40% / 40% 自动汇总。

### 2.5 AI 面试训练

1. 进入【AI 面试训练】，选择场景（技术岗 / 管理岗 / 综合素质）与题量（标准 3 题 / 完整 5 题）；
2. 点击【开始训练】，阅读题目后在输入框作答，点击【提交作答并评分】；
3. 系统给出**逻辑性、完整性、表达力**三个维度分数与总分，并给出点评与改进示范；
4. 点击【下一题】继续，全部完成后点击【结束并生成报告】查看维度均分与提升建议；
5. 历史训练记录在页面下方列表中查看。

> 作答建议：使用"结论先行 → 分点论述 → 实例支撑"的结构，可显著提升逻辑性与完整性得分。

### 2.6 政策问答

1. 进入【政策问答】，在输入框提问（如"应届毕业生到基层就业有补贴吗？"）并回车；
2. 回答下方会列出**政策来源**（标题 + 发布单位），可据此核对原文；
3. 右侧政策库支持按标题/标签检索，共 50 条政策；点击政策可查看详情（自动累计浏览量）。

## 3. 辅导员操作指南

1. 【就业数据看板】：查看就业率、行业分布、薪资分析、投递趋势，掌握班级/学院整体情况；
2. 【岗位匹配】：可为学生发布就业岗位（填写任职要求时用逗号分隔技能关键词，便于智能匹配）；
3. 【实习管理】：
   - 在"待审批实习申请"中查看待办；
   - 点击【审批】，选择【通过】（流转到下一节点）或【驳回】（回退到上一节点），并填写审批意见；
   - 对学生日志进行批阅（填写评语与分数），系统同时生成智能体点评；
4. 【政策问答】：查看"咨询热点统计"接口（`/api/policies/hot`），了解学生高频问题，用于针对性宣讲；
5. 学生档案查询通过 `/api/users` 接口按角色、关键词筛选。

## 4. 企业 HR 操作指南

1. 【岗位匹配】→【发布岗位】：
   - 填写岗位名称、企业名称、岗位类别、城市、薪资范围、学历要求、截止日期；
   - **任职要求**请用逗号分隔关键词（如 `Java,Spring Boot,MySQL`），这是智能匹配的依据；
2. 岗位发布后学生即可检索、匹配与投递；
3. 通过 `/api/jobs/applications` 查看投递列表，使用
   `/api/jobs/applications/{id}/status` 更新为 `VIEWED`（已查看）、`INTERVIEW`（面试中）、`OFFER`（录用）或 `REJECTED`（未通过）；
4. 作为企业导师参与实习审批（流程首节点）与三方评分中的企业导师评分。

## 5. 院系管理员操作指南

1. 【就业数据看板】：查看全院就业率、行业分布、薪资分析与平台总量指标；
2. 【用户查询】：通过 `/api/users` 查看全院学生/辅导员档案，支持按角色与关键词筛选；
3. 【岗位管理】：可下线不合规岗位（`DELETE /api/jobs/{id}`）；
4. 【实习审批】：作为流程末节点审批，通过后实习申请归档（状态 `PASSED`，计入就业率）；
5. 【政策库】：政策数据由 `deploy/sql/data.sql` 初始化，新增条目可直接入库或使用后台接口（第 3 周开发）。

## 6. 常见问题

| 问题 | 解决办法 |
| --- | --- |
| 登录提示"用户名或密码错误" | 确认账号与密码（演示账号密码为 `123456`） |
| 菜单比同学少 | 菜单按角色显示，属正常现象（如学生看不到"发布岗位"） |
| 匹配分数偏低 | 补全档案中的技能标签与求职意向，技能关键词需与岗位要求用词一致 |
| 简历诊断提示"未提供正文" | 需要在上传附件后补充"简历正文"文本（解析功能第 2 周上线） |
| 提问后回答为知识库原文 | 当前处于本地规则模式；配置大模型密钥后回答更自然 |
| 无法提交实习日志 | 申请被驳回（状态 REJECTED）时不可提交，请重新申请 |
| 页面数据不刷新 | 切换菜单或刷新页面，看板数据为实时统计 |
