### 2.1 具体交付物

1. **仓库与协作规范**
   - Git 分支模型：`main`（交付）/ `develop`（集成）/ `feature/*`、`fix/*`、`docs/*`；
   - 提交规范：`type(scope): subject`（feat/fix/docs/style/refactor/test/chore）；
   - PR 模板与评审流程（`CONTRIBUTING.md`、`.github/PULL_REQUEST_TEMPLATE.md`）。
2. **后端脚手架（Spring Boot 3 + Java 17）**
   - 分层结构：`common` / `config` / `security` / `agent` / `modules`；
   - 统一响应 `Result`、统一异常处理、统一时间序列化、分页插件与防全表更新拦截；
   - JWT 认证 + 四类角色授权（`@PreAuthorize` + 数据归属校验）；
   - 八大业务模块骨架：认证、用户档案、智能简历、岗位匹配、实习管理、面试训练、政策问答、数据看板；
   - 智能体层：`AgentOrchestrator` + 提示词库 + 大模型客户端（OpenAI 兼容）+ 本地规则引擎降级；
   - 已完成编译验证：主代码 0 错误，产出 97 个类文件；单元测试 3 个测试类覆盖 JWT、规则引擎与匹配打分。
3. **前端脚手架（Vue 3 + TS + Vite + Element Plus）**
   - 登录页、看板、简历、岗位、实习、面试、政策、档案八个页面骨架；
   - 统一请求封装（令牌注入、401 自动跳转、统一错误提示）、路由守卫与按角色菜单；
   - ECharts 组件封装（就业率、行业分布、薪资分析、投递趋势）。
4. **数据库与部署**
   - 8 张业务表建表脚本（`deploy/sql/schema.sql`）；
   - 初始化数据脚本（`deploy/sql/data.sql`）：6 个账号、2 份简历、12 个岗位、11 条投递、6 条实习申请、3 条实习日志、2 次面试训练、**50 条就业政策**；
   - `docker-compose.yml` + 前后端 `Dockerfile` + `nginx.conf`，一条命令启动 MySQL/Redis/后端/前端。
5. **标准文档（课程要求 7 类交付物）**
   - 《系统功能分析说明书》《系统接口设计文档》《系统详细设计》《数据库设计说明》
     《系统安装部署文档》《系统操作说明书》已完成初稿；《源文件说明》由仓库 README 承担；
   - 《项目开发规范》覆盖目录分层、命名、编码、接口、数据库、Git、文档与质量要求。
