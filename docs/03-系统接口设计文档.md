| 项 | 内容 |
| --- | --- |
| 文档版本 | v0.1（与代码分支 `develop` 同步） |

## 1. 通用约定

### 1.1 请求约定

| 项 | 约定 |
| --- | --- |
| 协议 | HTTP/1.1（JSON）；实时通道使用 WebSocket(STOMP) |
| 编码 | UTF-8 |
| 认证 | 请求头 `Authorization: Bearer <token>` |
| 时间格式 | `yyyy-MM-dd HH:mm:ss`（日期为 `yyyy-MM-dd`） |
| 文件上传 | `multipart/form-data`，单文件 ≤ 10MB |

### 1.2 响应约定

```json
{
  "code": 20000,
  "message": "操作成功",
  "data": { },
  "timestamp": 1760000000000
}
```

分页 `data` 结构：

```json
{
  "records": [],
  "total": 128,
  "pageNum": 1,
  "pageSize": 10
}
```

### 1.3 错误码表

| code | HTTP | 含义 | 处理建议 |
| --- | --- | --- | --- |
| 20000 | 200 | 成功 | — |
| 40000 | 200 | 参数不合法 | 检查字段校验提示 |
| 40100 | 401 | 未登录或令牌失效 | 前端清除令牌并跳转登录页 |
| 40300 | 403 | 角色无权限 | 提示"当前角色无权访问" |
| 40400 | 200 | 资源不存在 | 提示并返回列表页 |
| 60003 | 200 | 用户名或密码错误 | 提示重新输入 |
| 60004 | 200 | 账号被停用 | 联系管理员 |
| 60021 | 200 | 岗位已停止招聘 | 刷新岗位列表 |
| 60022 | 200 | 已申请过该岗位 | 跳转"我的投递" |
| 60030 | 200 | 当前流程节点不允许该操作 | 刷新待办列表 |
| 60050 | 200 | AI 服务调用失败 | 系统通常已自动降级，可重试 |
| 50000 | 200 | 系统错误 | 记录时间点后反馈开发组 |

### 1.4 角色标识

`STUDENT` 学生、`COUNSELOR` 辅导员、`HR` 企业HR、`COLLEGE_ADMIN` 院系管理员。

### 5.1 审批（API-27）

请求：`{ "approve": true, "comment": "实习内容与专业相关，同意" }`

响应 `data` 关键字段：`currentNode`（流转后的节点）、`status`（`RUNNING`/`PASSED`/`REJECTED`）、`flowTraceJson`（完整轨迹）。

### 5.2 三方评分（API-31）

请求：`{ "role": "MENTOR", "score": 95 }`；`role` 取值 `SELF`（学生自评 20%）、`MENTOR`（企业导师 40%）、`TEACHER`（校方 40%）。
系统在每次提交后自动重算 `finalScore`。

## 8. 实时通道（WebSocket）

| 项 | 约定 |
| --- | --- |
| 端点 | `ws://<host>/ws`（STOMP over SockJS） |
| 应用前缀 | `/app` |
| 订阅前缀 | `/topic`、`/queue` |
| 用途 | 面试训练流式评分推送（`/topic/interview/{sessionId}`）、政策问答流式输出 |
| 现状 | 通道已搭建（`WebSocketConfig`），第 4 周接入流式输出 |

## 9. 智能体输出结构约定

所有由智能体生成的结果都以 JSON 返回，前端按字段渲染；若模型输出无法解析为 JSON，则返回
`{ "raw": "<原文>", "parseError": "<原因>" }`，接口不会因此报错。

| 场景 | 关键字段 |
| --- | --- |
| 简历诊断 | `overallScore`、`level`、`strengths`、`weaknesses`、`suggestions`、`missingKeywords` |
| 岗位匹配 | `matchLevel`、`reasons`、`gaps`、`applicationAdvice` |
| 面试评估 | `logicScore`、`completenessScore`、`expressionScore`、`comment`、`highlights`、`improvements` |
| 政策问答 | `answer`、`citations`、`followUpQuestions` |
| 实习日志点评 | `score`、`comment`、`suggestions` |
