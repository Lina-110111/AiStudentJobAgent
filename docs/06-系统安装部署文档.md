## 1. 环境要求

### 1.1 方式一：Docker 部署（推荐）

| 组件 | 版本要求 | 说明 |
| --- | --- | --- |
| Docker Engine | 24.0+ | 含 Docker Compose v2 |
| 操作系统 | Windows 10/11、Ubuntu 20.04+、macOS | 开发与演示均可用 |
| 内存 | ≥ 4GB（建议 8GB） | MySQL 约 500MB，后端约 700MB |
| 磁盘 | ≥ 5GB 可用空间 | 镜像与数据卷 |
| 网络 | 首次构建需可访问镜像仓库与 Maven/npm 仓库 | 可用国内镜像加速 |

### 1.2 方式二：本地开发

| 组件 | 版本要求 |
| --- | --- |
| JDK | 17（推荐 Temurin 17） |
| Maven | 3.8+ |
| Node.js | 18+（推荐 20 LTS） |
| MySQL | 8.0+ |
| Redis | 7.x（可选，缺失不影响主流程） |

## 2. 方式一：Docker 一键部署

### 2.1 获取代码

```bash
git clone <项目仓库地址> ai-job-agent
cd ai-job-agent
```

### 2.2 准备配置

```bash
# Windows: copy .env.example .env
cp .env.example .env
```

按需修改 `.env`：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `DB_PASSWORD` | `root123456` | MySQL root 密码，生产必须修改 |
| `DB_PORT` | `3306` | 宿主机映射端口，冲突时修改 |
| `FRONTEND_PORT` | `8081` | 前端访问端口 |
| `BACKEND_PORT` | `8080` | 后端接口端口 |
| `JWT_SECRET` | 示例值 | **生产必须替换**，长度 ≥ 32 字节 |
| `AI_ENABLED` | `false` | `false` 使用本地规则引擎，`true` 调用大模型 |
| `AI_API_KEY` | 空 | 大模型密钥；接入本地 Ollama 时可留空 |

### 2.3 启动

```bash
docker compose up -d --build
```

首次启动会自动完成：拉取镜像 → 构建后端（Maven 打包）→ 构建前端（npm build + Nginx）→
初始化 MySQL（执行 `deploy/sql/schema.sql` 与 `data.sql`）。

### 2.4 验证部署

| 检查项 | 命令 / 地址 | 期望结果 |
| --- | --- | --- |
| 容器状态 | `docker compose ps` | 4 个容器均为 `Up`（mysql 为 `healthy`） |
| 后端健康 | http://localhost:8080/actuator/health | `{"status":"UP"}` |
| 接口文档 | http://localhost:8080/swagger-ui.html | 可打开且分组完整 |
| 前端 | http://localhost:8081 | 显示登录页 |
| 登录联调 | 用 `student01 / 123456` 登录 | 进入就业数据看板 |
| 数据初始化 | 登录后看"政策问答"页 | 政策库共 50 条 |

### 2.5 常用运维命令

```bash
docker compose logs -f backend      # 查看后端日志
docker compose restart backend      # 重启后端
docker compose down                 # 停止（保留数据卷）
docker compose down -v              # 停止并删除数据（谨慎，会清空数据库）

# 数据库备份与恢复
docker exec job-agent-mysql sh -c 'exec mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" job_agent' > backup.sql
docker exec -i job-agent-mysql sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD" job_agent' < backup.sql
```

### 2.6 Docker 镜像交付（课程要求"包括 docker 镜像文件"）

镜像可通过两种方式交付：

```bash
# 1) 构建并导出为 tar 文件（离线交付给老师/答辩机）
docker compose build
docker save job-agent-backend:latest  -o job-agent-backend.tar
docker save job-agent-frontend:latest -o job-agent-frontend.tar

# 2) 在目标机器导入
docker load -i job-agent-backend.tar
docker load -i job-agent-frontend.tar
```

> 说明：后端与前端镜像中已包含运行所需的全部依赖（JRE 17 / Nginx），
> MySQL 与 Redis 使用官方镜像 `mysql:8.0`、`redis:7-alpine`，无需额外构建。

## 3. 方式二：本地开发部署

### 3.1 初始化数据库

```bash
mysql -uroot -p < deploy/sql/schema.sql
mysql -uroot -p job_agent < deploy/sql/data.sql
# 校验政策条目数量（应 >= 50）
mysql -uroot -p job_agent -e "SELECT COUNT(*) FROM policy_item;"
```

### 3.2 启动后端

```bash
cd backend
mvn clean package -DskipTests        # 或直接 mvn spring-boot:run
java -jar target/job-agent-backend.jar
```

数据库连接可通过环境变量覆盖，也可修改 `src/main/resources/application-dev.yml`：

```bash
DB_HOST=localhost DB_USERNAME=root DB_PASSWORD=yourPassword mvn spring-boot:run
```

### 3.3 启动前端

```bash
cd frontend
npm install
npm run dev            # 开发模式：http://localhost:5173，已配置 /api 代理
npm run build          # 生产构建，产物在 dist/
```

### 3.4 接入大模型（可选）

```bash
export AI_ENABLED=true
export AI_PROVIDER=deepseek
export AI_BASE_URL=https://api.deepseek.com
export AI_MODEL=deepseek-chat
export AI_API_KEY=sk-xxxxxxxx
mvn spring-boot:run
```

本地 Ollama 示例：

```bash
ollama pull qwen2.5:7b
export AI_ENABLED=true AI_PROVIDER=ollama AI_BASE_URL=http://localhost:11434 AI_MODEL=qwen2.5:7b AI_API_KEY=
```

启动后访问 `GET /api/ai/status` 确认 `degraded=false`。

## 4. 关键配置项

| 配置项 | 位置 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `server.port` | `application.yml` | 8080 | 后端端口 |
| `spring.datasource.url` | `application.yml` | `jdbc:mysql://localhost:3306/job_agent` | 数据库连接 |
| `spring.data.redis.*` | `application.yml` | localhost:6379 | Redis 连接 |
| `app.jwt.secret` | `application.yml` | 示例密钥 | JWT 签名密钥 |
| `app.jwt.expire-minutes` | `application.yml` | 720 | 令牌有效期（分钟） |
| `app.ai.enabled` | `application.yml` | false | 是否启用大模型 |
| `app.ai.chat-path` | `application.yml` | `/v1/chat/completions` | OpenAI 兼容路径 |
| `app.storage.local-path` | `application.yml` | `./data/upload` | 上传文件目录 |
| `spring.servlet.multipart.max-file-size` | `application.yml` | 10MB | 上传大小限制 |

## 5. 常见问题排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 后端启动报数据库连接失败 | MySQL 未启动 / 密码错误 | 检查 `DB_HOST`、`DB_PASSWORD`；确认 3306 可访问 |
| 启动报 `Table 'job_agent.xxx' doesn't exist` | 未执行建表脚本 | 执行 `deploy/sql/schema.sql` |
| 登录返回 60003 | 密码错误 | 演示账号密码为 `123456` |
| 接口返回 40100 | 令牌过期或未携带 | 重新登录；确认请求头 `Authorization: Bearer <token>` |
| 接口返回 40300 | 角色无权限 | 用对应角色账号登录（如发布岗位需 HR/辅导员） |
| 政策问答回答为"本地知识库检索结果" | 未启用大模型 | 配置 `AI_ENABLED=true` 与 `AI_API_KEY`，或接受降级效果 |
| 前端刷新 404 | Nginx 未配置 SPA 回退 | 确认使用仓库内 `frontend/nginx.conf` |
| 上传文件失败 | 类型或大小限制 | 仅允许 pdf/doc/docx/txt/png/jpg，≤10MB |
| Redis 连接失败但系统可用 | Redis 仅作增强能力 | 属正常降级；如需热点统计请启动 Redis |
